
# Device Tracking Map

## Overview
This project allows users to track and visualize the location of devices on a map in real-time using **Leaflet.js**, **Socket.io**, and **Node.js**. The app provides unique color-coded markers for each user, ensuring an easy way to identify each device's position. The map updates dynamically as users move, providing a live tracking experience.

### Features:
- **Real-time Location Tracking:** Devices update their positions on the map as they move.
- **Color-Coded Markers:** Each user gets a unique color for their marker, stored in the browser's local storage.
- **User Identification:** Each user gets a unique marker and color, making it easy to differentiate between devices.
- **WebSocket Communication:** Uses **Socket.io** for real-time communication between clients and server.

## Installation

To run the project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/device-track-map.git

2. **Navigate to the project folder:**
   ```bash
   cd map-track

3. **Install dependencies:**
   ```bash
   npm install
4. **Run the project**
   ```bash
   npm start
5. Open http://localhost:3000 in your browser to see the app in action.
